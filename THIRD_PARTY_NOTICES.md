# Drittanbieter und Weitergabe / Third-party notices

Stand / reviewed 2026-11-26. Diese Übersicht erfasst vorgesehene Komponenten und ihre Herkunft. Für ein Binärpaket sind die tatsächlich enthaltenen Versionen, transitiven Bibliotheken, Copyright-Vermerke und vollständigen Lizenztexte aus dem gebauten Artefakt zu erfassen. / This inventory covers candidate components. For each distributable, inventory the exact binaries, versions, transitive libraries, copyrights and full license texts in that artifact.

Die untersuchten Cleaner sind Vergleichsprojekte. Diese Recherche übernimmt keinen Programmcode daraus. Die PhotoMetaClean-Lizenz mit Verkaufsverbot gilt für den eigenen Projektcode. Die Lizenz eines Gesamtpakets ergibt sich aus den mitgelieferten Komponenten. / The reviewed cleaners are comparison projects. This review incorporates no code from them. The PhotoMetaClean no-sale license covers original project code. Each dependency in a distribution retains its own terms. [Projektvergleich / project review](research/03_GITHUB_PROJEKTE.md)

Der Linux-Builder integriert eine per SHA-256 festgelegte Runtime des AppImage-Projekts mit einem SquashFS-Dateisystem. Vor einer Binärfreigabe sind deren Lizenz und die Hinweise der im ELF enthaltenen Bibliotheken ebenfalls dem konkreten Build zuzuordnen. The AppImage packages include the runtime alongside the application. Source and runtime notices apply to the distributed components. [AppImage type2-runtime](https://github.com/AppImage/type2-runtime)

Der HEIC-Decoder verwendet pi-heif-decoder mit libheif und libde265. Für die Weitergabe sind die Hinweise und Lizenzen im konkreten Wheel maßgeblich. / HEIC decoding uses pi-heif-decoder with libheif and libde265. Review the notices and codec licenses in each distributed wheel. [pi-heif-decoder](https://pypi.org/project/pi-heif-decoder/)

Die Pakete enthalten ExifTool 13.64. macOS und Linux führen die mitgelieferten Perl-Quellen mit dem System-Perl aus. Windows enthält die offizielle portable Windows-Fassung mit Begleitdateien. Die Downloads werden gegen die vom Autor veröffentlichte SHA-256-Summe geprüft. / The packages include upstream ExifTool 13.64. macOS and Linux use the system Perl. Windows includes the portable upstream build and its support files. [Upstream checksums](https://exiftool.org/checksums-13.64.txt)

Qt und die HEIF-Decoder werden dynamisch geladen. Die Projektlizenz beschränkt keine durch die Fremdlizenzen eingeräumten Rechte, einschließlich des Ersetzens und Debuggens dieser Bibliotheken. Die Pakete enthalten Lizenztexte und ein Verzeichnis der Build-Versionen. / Third-party license rights, including replacing and debugging the Qt and HEIF shared libraries, are preserved. Packages include license files and a build-environment inventory.
