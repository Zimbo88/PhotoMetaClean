# Repository instructions / Projektregeln

## English

Read original research files only. Keep individual measurements, paths and reports in ignored private directories. Generate public test fixtures locally from synthetic inputs. Preserve provenance and pixel integrity in every editing feature. Run the relevant tests and the Git privacy guard before committing. Obtain explicit approval before publication. Keep public user documentation available in German and English.

## Deutsch

Öffne Forschungsoriginale ausschließlich lesend. Speichere Einzelmessungen, Pfade und Berichte in ignorierten privaten Verzeichnissen. Erzeuge öffentliche Testdaten lokal aus synthetischen Eingaben. Erhalte Herkunftsinformationen und Bildintegrität bei jeder Bearbeitungsfunktion. Führe vor einem Commit die einschlägigen Tests und den Git-Datenschutzguard aus. Hole vor jeder Veröffentlichung eine ausdrückliche Freigabe ein. Pflege öffentliche Benutzerdokumentation auf Deutsch und Englisch.
