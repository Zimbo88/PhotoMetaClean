# Security / Sicherheit

## English

Report a vulnerability privately to the maintainers. Use GitHub private vulnerability reporting when enabled. If no private channel is listed, request one in an issue and share technical details privately. Include the affected version, operating system, expected result and a minimal synthetic reproduction. Keep original photos, metadata dumps and absolute paths on your device.

If private data enters a published commit, contact the repository owner privately with the commit ID. Removing the file in a subsequent commit leaves earlier versions accessible. Coordinate history cleanup, existing downloads and any exposed credentials with the owner.

## Deutsch

Melde Schwachstellen vertraulich an die Projektleitung. Nutze die private Schwachstellenmeldung auf GitHub, sofern aktiviert. Fehlt ein vertraulicher Kontakt, frage in einem Issue nach einem Meldeweg. Übermittle Version, Betriebssystem, erwartetes Ergebnis und ein synthetisches Minimalbeispiel privat. Originalfotos, Metadatenauszüge und absolute Pfade bleiben auf deinem Gerät.

Falls private Daten in einem veröffentlichten Commit landen, melde der Projektleitung vertraulich die Commit-ID. Auch nach einem Löschcommit sind ältere Versionen abrufbar. Stimme die Bereinigung des Verlaufs, den Umgang mit vorhandenen Kopien und gegebenenfalls den Austausch offengelegter Zugangsdaten mit der Projektleitung ab.
